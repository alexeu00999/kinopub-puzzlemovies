# kinopub/kino.watch — двойные субтитры (RU + EN)

Userscript для Tampermonkey. Помогает учить английский на kino.watch: показывает русские субтитры второй строкой под английскими, перематывает по фразам, меняет скорость и по паузе показывает последние фразы с переводом.

## Возможности

- **Вторая строка субтитров (RU)** поверх плеера, любая из русских дорожек фильма.
- **Перемотка по фразам**: клавиши `,` и `.` прыгают к началу предыдущей или следующей английской фразы, паузы без диалогов пропускаются.
- **Скорость как на YouTube**: `Shift+,` и `Shift+.`, шаг 0.25 (от 0.25× до 2.0×). Значение на секунду показывается на экране.
- **История на паузе**: пробел ставит на паузу и показывает последние N фраз, под каждой английской её русский перевод.
- **Панель настроек** (кнопка **RU** справа сверху в плеере). Все настройки запоминаются.

## Установка

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/) для Chrome.
2. Если скрипты не запускаются, откройте `chrome://extensions`, найдите Tampermonkey, зайдите в «Сведения» и включите **Разрешить пользовательские скрипты**. В новых версиях Chrome это нужно сделать вручную.
3. Откройте файл `kino-dual-subs.user.js` в текстовом редакторе и скопируйте всё содержимое (`Ctrl+A`, `Ctrl+C`).
4. Нажмите иконку Tampermonkey, затем **Создать скрипт**. Удалите весь шаблон, вставьте код и нажмите `Ctrl+S`.
5. Убедитесь, что скрипт включён: в списке Tampermonkey переключатель должен быть зелёным.

### Обновление

Откройте существующий скрипт в Tampermonkey, замените весь код новой версией и сохраните (`Ctrl+S`). Затем обновите страницу фильма (`F5`). Не создавайте второй скрипт рядом со старым: две версии будут мешать друг другу.

## Как пользоваться

1. Откройте фильм на kino.watch и обновите страницу (`F5`). Скрипт должен перехватить манифест при загрузке.
2. Включите **английские субтитры** штатным меню плеера. Русские появятся жёлтым цветом над ними.
3. Нажмите кнопку **RU** справа сверху, чтобы открыть панель настроек.

### Горячие клавиши

| Клавиши | Действие |
|---|---|
| `,` / `.` | Фраза назад / вперёд |
| `Shift` + `,` / `Shift` + `.` | Скорость − / + |
| `Пробел` | Пауза. Если поставили на паузу, показываются последние фразы с переводом. Повторный пробел закрывает историю и продолжает фильм |
| `Esc` | Закрыть историю и панель |

Клавиши определяются по физическому положению, поэтому работают на любой раскладке (на русской это `б` и `ю`). Свои `,` и `.` скрипт перехватывает у плеера.

**Как работает перемотка по фразам.**
- `.` перематывает к началу следующей английской фразы.
- `,` повторяет текущую фразу, если с её начала прошло больше секунды. Повторное нажатие уходит к предыдущей фразе.
- Тайминги берутся с английской дорожки, выбранной в плеере (если английские субтитры выключены, берётся первая английская).
- Звуковые пометки вроде `(BANGING)` пропускаются, куски одного предложения склеиваются.

**История на паузе.** Показывается только когда фильм поставлен на паузу пробелом, а не кликом по видео. Закрывается пробелом, перемоткой или `Esc`.

### Панель настроек

| Блок | Что там |
|---|---|
| **Показ** | Переключатели: русские субтитры, история на паузе |
| **Русская дорожка** | Выбор дорожки. По умолчанию первая русская без пометки Forced. Дорожек несколько, и переводы у них могут различаться |
| **Настройка** | Сдвиг русских субтитров (шаг 0.5 с, клик по значению сбрасывает в 0), размер, высота над низом экрана, количество фраз в истории (1–20) |
| **Дорожки** | Статус загрузки русской и английской дорожек |
| **Горячие клавиши** | Памятка |

Панель закрывается кнопкой ✕, клавишей `Esc` или кликом вне панели.

## Что стоит знать

- Ссылки на субтитры подписаны токеном с ограниченным сроком. Если в статусе появилась ошибка, обновите страницу (`F5`).
- При переходе на другую серию скрипт сам подтягивает новые субтитры. Если не подтянул, обновите страницу.
- Русская дорожка может быть переводом не вашей версии фильма. Тогда подкрутите **Сдвиг**, а если строки совсем не совпадают, выберите другую русскую дорожку.
- Интерфейс скрипта изолирован от стилей сайта (Shadow DOM) и работает в полноэкранном режиме.
- Если видны две кнопки, значит, включены две версии скрипта. Отключите старую в списке Tampermonkey.
